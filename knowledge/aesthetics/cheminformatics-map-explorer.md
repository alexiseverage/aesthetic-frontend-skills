## Analysis

Cheminformatics Map Explorer is application-ready because its signal is distributed across all seven dimensions rather than resting on palette alone. The load-bearing pattern is: chemical-space map as primary stage + molecule structure preview panes + scientific metadata inspector pattern + restrained analytical palette. Frontend translation should begin with the spatial/object model, then apply the palette and texture as evidence of that model.

Recommended token direction: preserve the canonical palette roles, use the type system described above, set shape and spacing to match the source object's density, and reserve motion for workflow/state feedback.
