# Photographic Contact Sheet

## Scope and Context

A process vernacular of photographic editing: miniature positive frames retain strip order, frame/roll identifiers, material edges, and optional editorial marks. This is a coherent visual system derived from a working artifact, not a historically named art movement. Contact printing by itself is broader: one botanical cyanotype, one large-format contact print, a slide-mount array, or an arbitrary image grid does not establish this identity.

[Cleveland's PROOF exhibition](https://www.clevelandart.org/exhibitions/proof-photography-era-contact-sheet) explains the roll-film workflow and distinguishes working proofs from later complete-sheet artworks. [Princeton's Robert Frank record](https://artmuseum.princeton.edu/art/collections/objects/16422) documents editing within a sequence. The [National Gallery's Frank collection](https://www.nga.gov/artists/robert-frank-collection) distinguishes artist-printed sheets, work prints, and later technical material, and cautions that titles and dates can be descriptive or artist-supplied. [Magnum's collection](https://store.magnumphotos.com/collections/contact-sheets) provides creator-attributed reproductions across many photographers and film formats. Its modern mat/shadow product styling is excluded from the historical grammar.

## Analysis

### Claim-to-artifact map

- **Observed, defining:** repeated photograph windows plus stable sequence/index cues distinguish a contact sheet from a collage (M01, M02, M06, M16, M21, M28, M29, M30). Neither black paper nor red marks alone is necessary.
- **Observed, common:** hand-drawn frame selection, circled moments, arrows and archival headers create a second editorial hierarchy above capture order (M01, M03, M05, M09, M14, M19, M25, M28). Unmarked M04/M10/M20/M24 show that selection marks are optional in the historical artifact.
- **Observed, variant:** large-format/medium-format four-frame sheets and cream stamped-number sheets retain the system while changing density and background (M06, M18, M24, M25, M27).
- **Source-supported:** a sheet is a working editing/reference tool; printing the whole sequence can also produce a finished artwork. This distinction follows Cleveland and Princeton, not the appearance of wear.
- **Proposed interface translation:** immutable frame order, explicit selection state, a selected-only filter, larger frame review, and a useful export list. These behaviors are contemporary design choices. They are not historical claims.
- **Unknown:** exact original ink colors, print-paper reflectance, font identity for most labels, measured motion, native responsive rules, and every photographer's selection-code meanings.

### Boundary, connotation, and frontend suitability

Classify as a new process-derived aesthetic in `material-print-craft`. Cyanotype can also be contact printed, but chemistry/blue image formation is a different identity from multi-frame editing sheets. Color-infrared landscape specifies image formation/material-dependent false color, not editorial arrangement. Spirit photography uses exposure layering and supernatural representation; contact-sheet styling alone does not imply that subject.

Software suitability is strongest in photo selection, media libraries, portfolio case studies, editorial comparison, and review workflows. It can also support document/version comparisons when sequence is meaningful. Flat, rectangular controls, roll headers, fine metadata, and marked states carry the grammar into smaller components. It is less suitable for products without a meaningful media/sequence model; adding perforations to every form is superficial quotation.

Use contemporary interpretation with documentary restraint. Preserve image detail, give marks actual state meaning, and distinguish fictional demo imagery from authentic archival photography. Avoid sensationalizing the depicted people or attaching invented quotations to real photographers.

## Application Handoff

All following values are proposed screen values informed by the corpus, not measurements of historical objects.

| Role | Proposed value |
| --- | --- |
| Background / surface | `#151515` / `#222222` |
| Primary / muted text | `#F4F0E5` / `#BBB7AD` |
| Primary action / secondary | `#F4F0E5` / `#CBB66D` |
| Select accent | `#FF8065`, plus text/checkmark so color is not the sole signal |
| Display / body / mono | Georgia serif / Arial sans / system monospace; no downloaded font required |
| Heading / body / metadata | 44px/1.0, 16px/1.5, 12px/1.4; 700/400/400; labels 0.08em tracking |
| Corners / borders | 0px radii; 1px quiet rules; 2–3px irregular select outline separate from focus ring |
| Motion | Still by default; optional 120ms color change, removed under reduced motion; no autonomous film advance |
| Spacing | 4, 8, 12, 16, 24, 32px; 4–6 frame columns desktop, 2 mobile, larger review image below |

Include frame numbers, order-preserving windows, archival roll metadata, and editorial selection marks. Avoid instant-photo white-card stacks, ornamental camera icons, fake branded film data, and universal grunge.

| Component | Application note |
| --- | --- |
| Buttons | Rectangular paper/ink actions; 44px target; selected toggle uses `aria-pressed`, visible text and mark. |
| Cards | Flat proof field; consistent image ratio, metadata strip and restrained paper grain; no floating rounded shadows. |
| Inputs | Opaque flat field, visible label and contrasting 2px focus outline; do not fake handwriting for user text. |
| Navigation | Dense roll/sequence labels; active state underlined and named; no hover-only operations. |
| Hero/header | Restrained archival masthead, large editorial title, compact typed session metadata. |
| Headings | Readable serif/sans editorial hierarchy; no invented universal contact-sheet typeface. |
| Dividers | Fine rules or mechanical film tick strips; keep decoration nonsemantic. |
| Links | Underlined readable text on opaque surface, visibly focused. |
| Badges/tags | Small squared frame/roll identifiers; explicit selection text complements color. |
| Modals/overlays | Prefer an in-flow review panel; if modal is needed, labeled dialog with focus/escape/return behavior. |
| Alerts | Paper-label status with actual live announcement, never a fictional processing error. |
| Icons | Plain checks/arrows; scratches and sprockets are decoration, never sole controls. |

Flags: maintain contrast for tiny amber edge codes; never place essential text over variable imagery. Dark-mode contrast requires its own verification. Make the system work without color or animation. Too many scuffs/grease marks exhaust hierarchy. Added imagery must have its own provenance; source inspection grants no republication right. No cross-aesthetic blend is required.
