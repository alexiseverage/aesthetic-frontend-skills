# Polarized Crystal Photomicrography

A process-based photographic aesthetic in which crystalline structure, polarized illumination and the imaging setup produce visible fields of interference color, extinction, growth boundaries and fine material texture. This catalog label is a bounded visual tradition, not a new art movement or a name for every microscopic photograph. Crystalline organization and material-dependent contrast are central; unrestricted rainbow gradients are insufficient.

## Analysis

### Claim map and defining boundary

Structure-specific optical color and retained material texture distinguish this system from a freeform synthetic gradient: PB0/PB28/PB36/PB57, PF-adipic/PF-cholesterol and PW05. The field may contain repeated growth contours (PW04/PW19), long thin needles (PB27/PR-4058), ragged grain mosaics (PF-cholesterol/PB60), or broad fans (PF-atp/PF-atropine/PB61). Black gaps and extinction-like structures (PF-biotin) have independent support, but dark surround is optional (PZ01/PB5).

The common saturated palette must not be elevated into a universal rule. PB30 is gold-dominated, PR-4058 approaches monochrome, PZ01 is pastel and PW05 isolates one blue faceted crystal. PW09 uses additional diffraction-grating optics; its softness should be named as a mixed-method branch. Color and morphology cannot identify chemicals or disease from these reproductions. A photographic resemblance to a landscape does not turn the image into landscape photography.

### Frontend translation (inferred)

Build an image-comparison viewer, a photographic portfolio or a visual material-library article. Keep a bounded image region large enough for growth textures to remain legible. Pair image captions with plain material/method labels and photographer credits. Place essential controls on a stable opaque surface; variable rainbow fields cannot guarantee text contrast.

Selectable original artistic studies can load real image resources and show actual pending/error/retry states; avoid a decorative timer that pretends to report laboratory progress. Comparison must use related views of the same original application study when labelled as a process comparison. If synthetic imagery is used, call it an original illustration and avoid instrument readings or scientific-equivalence claims. A general hue rotation is not a calibrated polarization simulation.

On mobile, stack views or provide clear discrete tabs rather than forcing a narrow split. Labels, text alternatives, keyboard controls and visible selection indicators must work without dragging or color alone. Prefer still images. Optional image transitions are contemporary implementation choices removed under reduced motion. A load indicator should announce status without continuous flashing or needless full-screen movement.
