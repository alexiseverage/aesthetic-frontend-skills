## Analysis

Tactical sci-fi utility UI is a game/military HUD overlay system with a repeatable component grammar: reticles (bracket, circle, crosshair, triangular, hexagon-segment, ring), compasses, minimaps, weapon/ammo modules, hex frames, and mission data panels. The Synty Sci-Fi Soldier HUD pack documents this grammar explicitly, including animated reticle states (AimStart/AimWide) and module Idle/In/Out transitions.

The aesthetic is scoped to the game/military tactical overlay — the utilitarian interface language of first-person shooters and sci-fi games — distinct from `high-performance-hmi` (real, safety-oriented, grayscale-first operator doctrine) and `fictional-user-interface-diegetic` (cinematic screen graphics). The signature is the HUD overlay framing the viewport with corner-anchored modules and a center reticle.

For frontend translation, the useful rules are: cyan/teal/amber accents on dark or transparent backgrounds, technical monospace readouts, reticle/compass/minimap/hex-frame geometry, and screen-glow/wireframe texture. Motion claims are inferred from static evidence and must be inspected from motion artifacts before canonization.
