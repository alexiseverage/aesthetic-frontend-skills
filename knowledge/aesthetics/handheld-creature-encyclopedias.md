# Handheld Creature Encyclopedias

## Scope and classification

Distinct descriptive interface system for indexed creature knowledge/discovery, related to pixel rendering, device/book skeuomorphism and reference applications. Portable console, dedicated toy and phone descendants are explicitly differentiated. Later portable-console scenes are included as the continuing lineage, not misdated as early handheld LCDs. No single named historical movement is claimed.

## Source / Evidence Links

- [Tiger/Hasbro official Pokédex Deluxe manual](https://www.hasbro.com/common/instruct/89244.PDF): primary archive-list, portrait/biography and personal-log instructions. Selected full pages 5–6 inspected; printed monochrome diagrams do not establish actual casing colors.
- [Nintendo Pokémon Ranger manual](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/nintendo_ds_21/Manual_NintendoDS_PokemonRanger_EN.pdf) and [Guardian Signs manual](https://www.nintendo.com/eu/media/downloads/games_8/emanuals/nintendo_ds_21/Manual_NintendoDS_PokemonRangerGuardianSigns_EN.pdf): primary indexed record/search/sort diagrams, one system per manual.
- [Nintendo Spain Yo-kai Watch 3 Medallium guide](https://www.guiasnintendo.com/0a_NINTENDO_3DS/yo-kai-watch-3/guia-yo-kai-watch-3/yo-kai-pad-medalium.html): primary source distinguishes encountered creatures from friendship medals and describes dossier, location and ordering controls. Seven full original images were inspected as one game, not seven works.
- [Pokémon GO primary support](https://niantic.helpshift.com/hc/en/6-pokemon-go/faq/124-viewing-the-pokedex/?f=scanning-a-pokestop&p=web&s=top-articles): describes seen/caught/unknown representation, keyword search and category filters. It mentions registration animation; this corpus does not measure playback.
- [WikiDex official 3D Pro manual mirror](https://www.wikidex.net/wiki/Archivo%3AManual_de_Nintendo_3DS_de_Pok%C3%A9dex_3D_Pro.pdf): original Nintendo Spanish manual, selected complete long pages 5–6 plus native diagram detail inspected. Current original English URL was unavailable; the mirror is credited rather than falsely claiming direct Nintendo delivery.
- Bulbapedia original-file pages and Fandom original GO capture are individually linked below. They are research hosts, not UI authors. Source file metadata establishes complete tiny originals for early handhelds. Publisher/studio attribution is retained only where known; individual interface artists generally unidentified.

## Analysis

**Observed:** the task survives major style changes: selected creature plus indexed collection and explicit status. Electronic chrome is common, not mandatory. GO's unboxed matrix omits inline names/numbers in the inspected state, Arceus uses paper, and Quest uses an open book. Thus a red pixel device is an application branch rather than a universal rule. Early tiny originals were inspected natively and with explicitly labeled nearest-pixel views; no guessed small-screen details are retained.

**Source-supported:** Hasbro's toy combines an archive and personal log; Nintendo Ranger sources describe search/sort; Nintendo Spain distinguishes seeing from friendship; GO support distinguishes seen, caught and unknown. These functions are grounded, while exact present-day interfaces, timing, source fonts and responsive rules remain unknown.

**Proposed:** Fieldlink, a fictional field-index device with red shell, green-gray inset display, index/selected-specimen split, numbered records, habitat and status filters, number/name order, real seen/documented counters and editable per-record field notes. Six original vector creatures and original lore avoid copying characters. A working local export carries saved records. Stillness supports reading and comparison; there is no fake startup loader, mandatory audio or idle movement. All numeric CSS and breakpoints are authored, not recovered source values.
