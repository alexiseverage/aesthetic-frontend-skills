## Analysis

Manual records use landmarks, branch classes or silhouette cues. Photo tools add crop boxes and a ranked set of look-alikes. ExtractCompare explicitly asks for anatomical anchors; HotSpotter displays local feature correspondences; StripeSpotter can compare row codes; RAPID illustrates a named track among detections. Colors and numerical scores have method-specific meanings. The shared visual task is checking whether the same body region supports a proposed re-sighting. On angled, occluded or low-resolution input, a reviewer may need other views or an unmatched record.
