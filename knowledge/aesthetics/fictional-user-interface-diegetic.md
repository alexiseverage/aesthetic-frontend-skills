## Analysis

Fictional User Interface (FUI) is a named design discipline: the craft of designing screen graphics and interfaces for fictional worlds in film, games, and other media. Territory Studio is the canonical practitioner, and the discipline has a documented taxonomy. The diegetic/non-diegetic/spatial/meta framework — originating in Fagerholt and Lorentzon's 2009 Chalmers thesis "Beyond the HUD" — classifies interface elements by whether they exist within the fiction and within the 3D geometry.

The distinction between "screen graphics" (any motion design on a screen that gives life to a set or explains a story beat) and "FUI" (a technology interface — navigation, engineering, weapons, communications) is a useful scoping rule. The aesthetic's signature is the fictional screen: high-contrast data readouts, technical typography, wireframe geometry, and screen glow, layered over or within a diegetic scene.

For frontend translation, the useful rules are: technical monospace typography, dense data readouts, reticle/bracket/wireframe geometry, screen-glow and scanline texture, and a diegetic framing (the interface reads as an in-world screen). Motion claims are inferred from static evidence and must be inspected from motion artifacts before canonization.
