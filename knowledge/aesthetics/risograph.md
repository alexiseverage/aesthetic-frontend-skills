# Risograph

> **Origin**: Print-process aesthetic derived from stencil duplicator/riso production, contemporary zine culture, and small-run art publishing. The core UI translation is spot-color limitation plus visible print behavior.

## Analysis

_Analyzed: 2026-06-16 | Images reviewed: 0 | Analyst: implementation brief synthesis_

Risograph's UI value comes from the production process: stencil duplication, spot inks, overprint, halftone, and registration tolerance. Source material describes both the printing process and its contemporary art-publishing community.

### Color

Use a deliberately small ink set. Overprint should create extra tones through multiply behavior rather than adding a generic gradient palette.

### Typography

Typography may be assertive and poster-like, but body text needs enough cleanliness to survive grain and slight drift.

### Texture

Halftone, paper tooth, and misregistration are identity-bearing. They should be applied as repeatable overlays/masks rather than random distress.

### Motion

Animation is secondary. Ink-pass reveals and subtle registration slips work because they reference process.

### Layout

Editorial spreads, print-fair programs, poster stacks, and zine grids are the strongest spatial sources.
