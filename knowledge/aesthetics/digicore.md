# Digicore

A scoped grouping of personal release graphics and network circulation around a contested internet-music community. It is not a new music genre invented here, a universal youth identity or a claim that all later work by these artists shares one visual system. Contemporary revival is the proposed connotation mode.

## Analysis

The stable feature is a specific personal release in a peer circulation context, not obligatory noisy pixels. DG01's documented damage contrasts clean wordless DG04,07,14,26,29 and sparse DG28. Drawn DG21,23–25 and pixel DG18 are branches, not one mandatory syntax. Music producer credits do not identify visual authors. Visible checkerboard does not prove real alpha, light trails do not prove motion and apparent optical-disc packaging does not prove a manufactured format.

Modern application: original Common Folder release archive, readable neutral shell against individual cover worlds, native search/filter/selection, truthful local draft and metadata export. Proposed UI values, colors, interaction timing and file validation are application decisions, not extracted historical behavior. No fake player, borrowed recordings, automatic sound or claims of server upload.

## Connections

Hyperpop overlaps artists and distribution but its studied authored commercial-material/pop-world branch is not the same as this personal release/peer-circulation grammar. Myspace Chaos supplies profile customization, Glitch supplies damaged-image technique, Early Internet supplies publishing context and Emo supplies an emotional overlap; none alone establishes Digicore. Artist testimony overrides a platform tag. Separately useful canonical entry, related rather than a universal parent/child claim.
