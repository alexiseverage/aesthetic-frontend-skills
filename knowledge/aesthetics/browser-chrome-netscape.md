## Analysis

Browser chrome / Netscape-era browser UI is the application frame around the page, not the page content. It is the 1990s browser shell: beveled gray toolbars, the animated "throbber" logo (a blocky purple N whose pixel bevel alternated sticking out and going in to "throb"), the location field, and the bottom status bar that "negotiated with the world" as pages loaded one strip at a time.

The defining grammar is the chrome frame itself — persistent, beveled, and clearly separated from the content it contains. This is what distinguishes it from `early-internet`, which describes the page content and homepage culture. The throbber is the signature motion element, and the beveled 3D button edge is the signature texture.

For frontend translation, the useful rules are: a persistent beveled chrome frame (toolbar, location field, status bar), 3D beveled button edges, a throbber-style animated logo badge, and muted system-gray palette with brand accents. The result should read as a 1990s application shell, not as a modern browser.
