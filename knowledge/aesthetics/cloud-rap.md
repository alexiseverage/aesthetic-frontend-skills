# Cloud Rap

Scoped visual grouping around early-2010s networked rap releases, with Bay Area/US roots, a distinct Swedish peer branch and explicitly bounded later archives/continuations. It is not a claim that every affiliated artist's entire career or every pastel internet image belongs. Connotation mode: contemporary revival.

## Analysis

Material/image atmosphere plus a particular authored release context is more useful than a checklist of clouds and kanji. CR01/03/05/18/21/22 reject compulsory neon; CR02/15/16/23 reject compulsory soft landscape; CR17/25 reject treating all work as anonymous borrowed mood imagery. Artists' own words complicate outsider stereotypes. Referenced brands, bodies, games, Japanese scripts, religion and racial histories remain particular works, not free decorative stock.

Proposed contemporary application is Low Orbit, an original image postcard studio with three scenes, title/byline/frame/size controls and a real PNG export. Canvas, loading/error/race handling, contrast and reduced-motion choices are new functional design work. No songs, lyrics, artist imitation or automatic audio. A generated atmosphere is an application asset, never additional source evidence.
