## Analysis

Personal homepage builder / site-builder wizard is a tool-UI aesthetic: the visual language of 1990s WYSIWYG homepage builders (FrontPage, GeoCities PageBuilder, Intel's "page wizard"). The signature elements are wizard dialogs, clip-art galleries, background pickers, hit-counter and guestbook widgets, and the "preview/HTML" tabbed workflow.

This is distinct from `early-internet` (which describes the output — the pages) and `desktop-publishing` (print-era authoring). This is the web authoring-tool interface itself: the dialog-and-palette layout, the beveled buttons, the tiled background pickers, and the tabbed WYSIWYG/HTML/preview workflow. The evidence is thinner than for other candidates, but the authoring-tool UI is a defensible independent system.

For frontend translation, the useful rules are: system-gray wizard chrome, beveled dialog buttons, palette grids and background pickers, widget boxes (hit counter, guestbook), and a tabbed preview/HTML workflow. The result should read as a 1990s authoring tool, not as the page it produces.
