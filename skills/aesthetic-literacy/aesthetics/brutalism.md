## Scope

Brutalism is the architectural and later web-revival language of exposed structure, heavy mass, material candor, and anti-decorative directness. Historically it belongs to postwar civic buildings, housing, campuses, and public infrastructure; digitally it appears as raw browser defaults, stark hierarchy, and visible structure. Use it for institutional critique, architecture, design archives, experimental portfolios, or products that can sustain confrontation. It is not simply “ugly web design.”

## 7-Dimension Profile

**Palette**: Concrete gray, off-white, black, weathered beige, deep shadow, and restrained utility colors. Web variants can use black/white/default-link blue, but the historical base remains materially grounded.

**Type**: Blunt sans-serif, monospaced or utilitarian labels, signage-like caps, raw browser defaults in web revival variants, and hierarchy that privileges directness over refinement.

**Texture**: Exposed concrete, rough formwork marks, raw brick, board-marked surfaces, visible fasteners, unfinished surfaces, weathering, staining, and heavy shadow.

**Shape**: Block massing, cantilevers, repeated modules, hard rectangles, deep recesses, stair towers, ribbed facades, squared sensor housings, and no decorative softening.

**Motion**: Minimal, infrastructural, and functional. Abrupt reveals, snap transitions, or stark scroll thresholds are on-model; plush easing is not.

**Spatial**: Monumental scale, exposed circulation, repetitive grids, deep shadow, civic zoning, dense information clusters, and visible navigation frameworks.

**Cultural markers**: Postwar reconstruction, British social housing, civic campuses, concrete megastructures, Alison and Peter Smithson, ethical honesty of materials, web-brutalist raw HTML references, visible `<hr>`, underlined blue links, and default form controls.

## Non-Negotiables

**Non-negotiables**: exposed structural logic; heavy geometric mass; anti-decorative directness; high contrast; institutional or civic framing rather than generic edginess.

## Connotation

**Connotation**: Raw institutional force, candor, public seriousness, and anti-polish. Depending on context it can read as ethical honesty, civic weight, austerity, neglect, or deliberate confrontation.

## Related / Subsets

- `neubrutalism` — selectively revives rawness for contemporary UI with brighter color and friendlier play.
- `bauhaus` — shares functionalism but is lighter, pedagogically refined, and more systematic.
- `high-tech-architecture` — exposes structure too, but with technological lightness rather than concrete mass.
- Subsets include New Brutalism, web brutalism, and brutalist robotics.

## Frontend / UI Guidance

Make structure visible: plain links, hard borders, default controls, dense blocks, and clear labels can be intentional. Use weight and hierarchy rather than decorative polish. If translating architectural Brutalism, foreground mass, shadow, and material; if translating web brutalism, distinguish rawness from broken accessibility or careless UX.

## CSS Translation

- Palette tokens: `--concrete: #8d8d86; --weathered: #d6d0c2; --ink: #050505; --utility-blue: #0000ee; --hazard: #d71920;`.
- Use `border-radius: 0`, thick borders, visible outlines, default-style form controls, and blocky layout zones.
- Use flat concrete or noise texture sparingly; avoid glossy material simulation.
- Motion should be abrupt and purposeful: `transition: none` or short linear state changes.

## Typography / Fonts

Use system sans, Arial, Helvetica, Inter in blunt weights, IBM Plex Mono, Space Mono, or default browser fonts. Prefer direct labels and large type over refined editorial typography.

## Cultural / Ethical Notes

Brutalism is entangled with public housing, state infrastructure, class politics, preservation debates, and civic neglect narratives. Do not use it as a lazy synonym for ugliness, poverty, or institutional failure; when referencing housing or public services, avoid aestheticizing lived hardship.

## Anti-Patterns

Avoid soft rounded cards, decorative gradients, friendly mascot illustration, luxury serifs, fake dystopian grime, and broken usability passed off as honesty. If the interface is merely unfinished, it is not Brutalism.
