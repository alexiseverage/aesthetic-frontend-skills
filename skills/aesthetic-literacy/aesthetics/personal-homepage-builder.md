# Personal Homepage Builder / Site-Builder Wizard

## Scope

Personal Homepage Builder / Site-Builder Wizard is the authoring-tool interface of 1990s personal web creation: WYSIWYG editors, page wizards, background pickers, clip-art palettes, preview/HTML tabs, and widget dialogs. Use it when the tool that makes the page is the aesthetic subject. It is not the output page itself.

Evidence is thinner than some entries and remains limited; preserve that caveat. GeoCities and other named tools are historical references, not design assets to clone wholesale.

## 7-Dimension Profile

**Palette**: System-gray wizard chrome, off-white panels, muted dialog blues, default black text, and bright swatches inside background or hyperlink color pickers. The tool frame is subdued while selected assets can be loud.

**Type**: Small system sans-serif labels, dialog buttons, tab captions, form labels, file names, preview/HTML toggles, and occasional clip-art lettering. Large display typography belongs to page content, not the builder chrome.

**Texture**: Beveled buttons, inset fields, tiled background previews, dithered gradients, clip-art thumbnails, default table borders, and early GUI panel surfaces.

**Shape**: Wizard dialogs, tabbed panels, palette grids, preview panes, widget boxes, hit-counter controls, guestbook modules, table layout cells, and small modal buttons.

**Motion**: Mostly static task flow: tab switching, preview refresh, wizard next/back steps, and chooser dialogs. Avoid treating it as an animated homepage output system.

**Spatial**: Dialog-and-palette layout with controls beside or above a preview pane; WYSIWYG/HTML/preview modes; stacked property panels; table-based navigation controls.

**Cultural markers**: GeoCities PageBuilder, FrontPage, page wizards, "Homesteaders," clip-art galleries, background pickers, hit counters, guestbooks, and the transition from hand-coded pages to consumer authoring tools.

## Non-Negotiables

**Non-negotiables**: system-gray wizard/tool chrome; WYSIWYG or preview/HTML workflow; palette/picker grids; homepage widgets such as counters or guestbooks; authoring-tool framing. Without the tool frame it becomes early-internet page content.

## Connotation

This is nostalgic quotation of amateur web authorship and guided creativity. It connotes empowerment through clumsy tools, not polished professional web design.

## Related / Subsets

`early-internet` is the authored page output. `desktop-publishing` is print-oriented authoring. `browser-chrome-netscape` is the browser application shell rather than the builder UI.

## Frontend / UI Guidance

Use this for creation metaphors, onboarding wizards, playful editors, old-web generators, or educational tools. Keep actual modern editing affordances understandable; nostalgia should not hide save states, undo, publishing status, or accessibility.

## CSS Translation

Use beveled buttons, tab strips, inset preview frames, palette grids, swatch pickers, tiled-background thumbnails, status hints, and small widget mockups. Provide responsive layouts while retaining the dialog/palette hierarchy.

## Typography / Fonts

Use system UI fonts, compact labels, and occasional pixel/clip-art display only inside preview assets. Keep instructional text and controls readable.

## Cultural / Ethical Notes

Old personal pages often contained private, youth-authored, or abandoned personal material. Do not scrape or expose real pages as decoration; use fictional examples or permissioned archives.

## Anti-Patterns

- Styling the homepage output instead of the builder interface.
- Removing all system-gray chrome for a modern editor shell.
- Turning clumsy authoring history into mockery of amateur users.
- Hiding real product controls behind fake retro widgets.
