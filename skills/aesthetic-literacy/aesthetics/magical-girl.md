# Magical Girl

Magical Girl is application-ready because its signal is distributed across all seven dimensions rather than resting on palette alone. The load-bearing pattern is: transformation iconography + jewel/gloss surface language + heart/star/moon emblem grammar + empowerment-through-ornament tone. Frontend translation should begin with the spatial/object model, then apply the palette and texture as evidence of that model.

## Scope

Suitable for achievement systems, identity/profile states, onboarding transformations, loyalty tiers, youth culture projects, collectibles, and celebratory dashboards. Not suitable for sober administrative workflows or contexts where sparkly heroism trivializes user needs.

Preserve the whole system across interface scale: the aesthetic should survive in a hero, a card, an icon set, and a form state without relying on one decorative cue. If the product only needs a lighter reference, borrow one or two tokens while naming the result as an influence rather than the full aesthetic.

## Non-Negotiables

**Non-negotiables**:

- transformation iconography.
- jewel/gloss surface language.
- heart/star/moon emblem grammar.
- empowerment-through-ornament tone. If these are removed, the result becomes a generic adjacent style rather than Magical Girl.

## Connotation

**Nostalgic quotation or contemporary revival**. Apply the heroine-transformation grammar with enough modern spacing and accessibility to avoid costume parody; ironic pastiche should be reserved for explicitly camp projects.

## Typography / Fonts

Use Rounded cute sans for UI text, with emblematic display lettering for titles and badges for identity moments, headings, numerals, labels, or badges. Pair it with a neutral readable sans or serif for body text and controls. Avoid making all microcopy decorative; the aesthetic reads more strongly when focal typography contrasts with quiet support typography.

## Anti-Patterns

- Using only the palette while dropping the shape, texture, spatial, and cultural-marker system; that becomes generic moodboard styling rather than Magical Girl.

- Animating glow, grain, flash, or mechanical effects without reduced-motion and solid-surface fallbacks for critical content.
