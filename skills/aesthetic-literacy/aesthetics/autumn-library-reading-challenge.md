# Autumn Library Reading Challenge

Autumn Library Reading Challenge combines public-library program infrastructure with seasonal paper cues: registration folders, library-card fields, book pockets, checkout cards, date stamps, bookmarks, category prompts, sticker or stamp trackers, prize milestones, and librarian-readable instructions.

## Scope

Use it for reading programs, discovery, logging, branch events, or youth/family participation. Keep entry easy, tracking flexible, and completion rules visible. The seasonal layer should never make reading level, disability, language, format, or access into a barrier.

## 7-Dimension Profile

**Palette**: Use checkout-card cream, branch brown or burgundy, stamp blue, leaf rust, mustard, forest green, and pencil graphite. Keep form fields and category labels high contrast.

**Type**: Use library/institutional serif or humanist sans, typewriter/mono checkout data, rubber-stamp dates, shelf codes, and child-readable program headings. Avoid Dark Academia blackletter or precious bookish script.

**Texture**: Card stock, kraft pockets, date-stamp ink, pencil logs, laminated bookmarks, folder tabs, glue wear, book cloth, and photocopied instruction sheets create the program kit.

**Shape**: Use library cards, book pockets, stamp grids, bookmark strips, shelf labels, folder tabs, category badges, progress rows, due-date boxes, and prize/milestone slips.

**Motion**: Use stamp placement, card insertion, log update, category completion, or shelf-code scan. Reduced motion updates stamps immediately and preserves a text progress count.

**Spatial**: Compose as tracker/log primary, with reader card or pocket rail, categories and milestones visible, and librarian instructions in a stable footer or side panel.

**Cultural markers**: Markers include branch names, card/shelf codes, reading logs, multiple formats, category prompts, bookmarks, stickers/stamps, librarian recommendations, registration folders, milestones, and program completion.

## Non-Negotiables

**Non-negotiables**: library card/pocket material + readable tracking system + category or milestone structure + inclusive program instructions.

## Connotation

**Mode:** contemporary library-program vernacular. Seasonal warmth should make participation welcoming without becoming elite, nostalgic, or prescriptive about what counts as reading.

## Related / Subsets

Unlike Dark Academia it is public, accessible, and programmatic; unlike Classroom Bulletin Board it tracks reading across home/library rather than classroom jobs; unlike Storybook Spooky Cute it is a participation system, not one narrative.

## Frontend / UI Guidance

Support book/audiobook/ebook/comic formats, manual or assisted logging, category prompts, branch events, recommendations, milestone status, privacy controls, and printable/offline tracking. Avoid public ranking.

## CSS Translation

- Roles: `--card-cream`, `--pocket-kraft`, `--stamp-blue`, `--leaf-rust`, `--branch-burgundy`, `--shelf-green`.
- Use ruled cards, date stamps, pocket folds, tab labels, bookmark strips, and localized paper wear.
- Square cards and pockets with small 0-3px wear; stamps may be round/irregular.
- Use log/tracker field plus pocket/card rail and category/milestone strip.
- Motion: 150-300ms stamp/card insertion; reduced motion updates directly with numeric progress.

## Typography / Fonts

Use an accessible institutional serif or sans with mono card/date data and restrained stamp treatment. Support multilingual scripts and do not use tiny faux-typewriter text for instructions.

## Cultural / Ethical Notes

Protect patron privacy, avoid public reading rankings, support different abilities/languages/formats, and make prizes equitable. Do not imply slow readers, audiobook users, or readers needing assistance are less successful.

## Anti-Patterns

- Cozy books-and-leaves mood board with no program mechanics.
- Dark Academia styling for a public children's program.
- Public leaderboards or exposed patron history.
- Only print books counting toward progress.
- Tiny low-contrast checkout-card text.
